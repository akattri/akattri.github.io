## Building

- **[Seashell](/projects/seashell/)**  
  Writing a Unix command-line shell from scratch in C to demystify process creation (`fork`), program execution (`execvp`), process reaping (`waitpid`), I/O redirection (`dup2`), and pipelines (`pipe`).
- **[Thread-Safe Concurrent Queue](/projects/thread-safe-queue/)**  
  Implementing a bounded multi-producer, multi-consumer FIFO queue in C using POSIX threads (`pthreads`), mutex locks, and condition variables to explore race conditions, deadlock prevention, and thread synchronization.
- **Systems & Telemetry Experiments**  
  Prototyping lightweight utilities in Python and C to inspect GPU memory, VRAM allocation, and inference latency during local model execution.
