## 1. Completed Foundations

### Harvard University: CS50x — Introduction to Computer Science
*Completed 2026*

CS50x served as an intensive foundation in computational thinking and rigorous problem solving.
- **Language Foundations**: C (weeks 0–5), Python, SQL, HTML/CSS/JavaScript.
- **Memory & Low-Level Mechanics**: Manual memory allocation (`malloc`, `free`), pointer arithmetic, memory leaks with Valgrind, stack vs. heap allocation, buffer overflows.
- **Data Structures in C**: Implemented custom dynamic arrays, singly and doubly linked lists, hash tables with collision resolution (separate chaining), and prefix tries for dictionary lookups.
- **Algorithmic Complexity**: Asymptotic notation ($\mathcal{O}$, $\Omega$, $\Theta$), sorting algorithms (selection sort, bubble sort, insertion sort, merge sort), binary search.
- **Relational Databases**: Structured queries, schema normalization, joins, table indexing, ACID properties.

### Linux Systems & Tooling
*Continuous self-directed study & practical administration*

- **Distributions**: Multi-year daily-driver experience across Debian, Fedora, and Ubuntu.
- **Core Topics**: Process lifecycles (`ps`, `top`, `kill`, `htop`), POSIX file permissions and ACLs, directory hierarchy standard (FHS), shell scripting with Bash, environment variables, standard streams (`stdin`, `stdout`, `stderr`) and I/O redirection.
- **System Utilities & Diagnostics**: Text processing (`grep`, `awk`, `sed`, `find`), network diagnostics (`netstat`, `ss`, `curl`), build automation with `make`.
- **Certification**: Completed the **Linux Essentials** course/certification covering Linux internals, open-source licensing, and foundational security.
